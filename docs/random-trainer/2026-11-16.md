# Random trainer

Random is a saved trainer-picker mode. Start picks one real trainer, excluding
the previous random draw in this app session. That trainer's name, figure,
recorded pack and device fallback stay together through Pause, Resume, side
changes, and completion. Start again picks again. Leaving clears the active
trainer but retains the Random preference. Fixed choices disable Random.
Draws do not write selected trainers into the account's saved preferences.

Validation: 72 test files / 1,807 tests passed, typecheck passed, production-base
build passed and 288 routes prerendered. Session-flow test verifies selection
before intro/media unlock, stable Pause/Resume/finish, and cleanup. Random pool,
no immediate repeats, old-settings defaults and synced preference are tested.
Trainer picker was visually inspected at 390x844 in Korean: readable two-column
cards, clear Random selection, no horizontal overflow. Existing fixed trainer
selection/greeting regression tests passed.

No voice assets, music routing or silent-switch behavior were changed. This is
not evidence of solving music takeover or physical iPhone finish-cue output.
